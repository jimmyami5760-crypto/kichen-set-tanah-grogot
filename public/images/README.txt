Taruh foto hasil kerja asli di folder ini (format .jpg / .webp, lebar 1200-1600 px, ukuran < 300 KB per foto).

Contoh:
  public/images/dapur-minimalis-1.jpg

Lalu isi di lib/content.ts pada portfolioItems:
  image: "/images/dapur-minimalis-1.jpg"

Selama field `image` kosong, website menampilkan placeholder gradasi.
